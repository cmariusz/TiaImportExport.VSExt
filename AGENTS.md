## CMsoft Import for TiaPortal

TIA Portal projects are mirrored into `TiaExport/` and imported back with the **CMsoft Import for TiaPortal** VS
Code extension. The complete instructions (TIA Portal Openness API reference, SimaticML XML conventions, the 26
`tia_*` Language Model Tools, build commands, autonomous compile-fix loop) are shared with GitHub Copilot:

- [.github/instructions/tia-import.instructions.md](.github/instructions/tia-import.instructions.md);
- [.github/instructions/tia-import-cli.instructions.md](.github/instructions/tia-import-cli.instructions.md) —
  the MCP server and the CLI bridge.

**Driving TIA Portal from an agent:** the extension runs a built-in **MCP server** (enabled by default). Read
`.tia/mcp.json` in this workspace for the endpoint and bearer token, then connect your MCP client to
`http://<host>:<port>/mcp` with `Authorization: Bearer <token>` and call the `tia_*` tools (start with
`tia_connect`).

Code style:

- Edit `.xml` / `.scl` / `.s7dcl` / `.s7res` files using the rules of `tia-import.instructions.md`.
- Do not hand-edit `.s7dcl` blocks as SCL — they are LAD/FBD source.
- Do not modify files under `.tia-cache/` or `TiaExport/` — those are regenerated by the extension.
- Keep changes scoped to the requested task. Avoid drive-by reformatting of TIA-generated files — the
  line-by-line diff is what the bridge uses to decide what to push back into TIA Portal.
- Always run `tia_compile` before submitting.
